# ⛔ 最高优先级规则（每次对话必读，不可跳过）

**任何对外操作，执行前必须让用户确认，一步都不许跳。**

包括但不限于：
- 发送邮件（不管发给谁、发几封）
- 设置定时任务（at、cron、systemd timer 等）
- 群发消息
- 推送到外部仓库
- 任何不可撤回的操作

流程铁律：
1. 先展示完整预览（收件人、标题、内容、附件、发送时间）
2. 等用户明确说"发"或"确认"
3. 再执行

**曾犯错误：**

- 之后又犯过同样错误，不止一次
- 犯的错写成记忆也没用，换个会话照犯

**如果做不到这条，就不配待在这台服务器里。**
